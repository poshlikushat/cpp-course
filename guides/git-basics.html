Git с нуля: как сохранить и сдать домашку

Git запоминает историю изменений твоего кода. Чтобы сдать домашнее задание, нужно сохранить изменения (коммит) и отправить их на GitHub (пуш).

Проверить, что изменилось

git status

Покажет, какие файлы ты изменил или добавил.

Добавить файлы в коммит

git add .

Команда git add . добавляет вообще все изменённые файлы. Можно указать конкретный файл: git add main.cpp.

Сохранить изменения (коммит)

git commit -m "Решил задачу про циклы"

После -m пиши короткое понятное описание того, что сделал.

Отправить изменения на GitHub

git push

После этого изменения появятся в репозитории на GitHub — задание сдано.

Обычный порядок действий: git status → git add . → git commit -m "..." → git push. Так можно делать много раз за день, каждый раз, когда что-то доделал.

Забрать новые изменения (если что-то поменяли в задании)

git pull
Если git push ругается на ошибку — не паникуй и не удаляй папку. Сделай скриншот ошибки и покажи преподавателю.
