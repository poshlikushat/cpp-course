Как создать SSH-ключ и подключить его к GitHub

SSH-ключ — это способ доказать GitHub, что это именно ты, без ввода пароля каждый раз. Ключ состоит из двух частей: приватной (никому не показываем, она остаётся у тебя на компьютере) и публичной (её мы добавим в настройки GitHub).

Шаг 1. Открой терминал

На Mac: найди приложение «Терминал» (Terminal) через Spotlight (⌘ + Пробел, набери «Terminal»).
На Windows: открой «Git Bash» (устанавливается вместе с Git) или PowerShell.

Шаг 2. Сгенерируй ключ

Введи команду:

ssh-keygen

На все вопросы можно просто нажимать Enter, чтобы оставить настройки по умолчанию (в том числе можно оставить пустой пароль — просто ещё раз нажми Enter).

Ключ сохранится в папку ~/.ssh/. Файл id_rsa — приватный (секретный), файл id_rsa.pub — публичный (его и будем добавлять на GitHub). В конце команда сама напечатает путь, куда сохранила ключ — можно свериться с ним.

Шаг 3. Скопируй публичный ключ

На Mac:

pbcopy < ~/.ssh/id_rsa.pub

На Windows (Git Bash):

cat ~/.ssh/id_rsa.pub | clip

Ключ скопирован в буфер обмена — можно вставлять (Ctrl+V / ⌘+V).

Шаг 4. Добавь ключ на GitHub

  1. Зайди на github.com/settings/keys
  2. Нажми «New SSH key»
  3. В поле «Title» напиши название, например «Мой ноутбук»
  4. В поле «Key» вставь скопированный ключ (Ctrl+V / ⌘+V)
  5. Нажми «Add SSH key»

Шаг 5. Проверь, что всё работает

ssh -T git@github.com

Если увидишь сообщение вида «Hi username! You've successfully authenticated...» — всё готово, можно переходить к клонированию репозитория.

Если появится вопрос «Are you sure you want to continue connecting?» — смело пиши yes и жми Enter.
