Как получить задание и склонировать его себе

Репозиторий с заданием, который дал преподаватель, — общий для всех учеников, и писать (пушить) в него напрямую нельзя. Поэтому сначала нужно сделать свою собственную копию репозитория на GitHub, а уже её склонировать к себе на компьютер. Тогда всё, что запушишь, будет попадать в твою копию, без конфликтов с другими учениками.

Перед этим шагом должен быть настроен SSH-ключ — см. гайд про SSH-ключ. Это всё актуально только для своего компьютера. Если ты в школе за общим компьютером — тебе сюда: гайд для школьного компьютера.

Шаг 1. Создай свою копию репозитория

Открой ссылку на репозиторий задания (её даёт преподаватель). Вместо обычной кнопки «Code» там будет зелёная кнопка «Use this template» — нажми её.

  1. В диалоге «Create a new repository» выбери себя в качестве владельца (Owner)
  2. Введи любое название, например day01-hello-cpp
  3. Нажми «Create repository from template»

GitHub создаст новый репозиторий у тебя в аккаунте с теми же файлами — это уже твоя личная копия.

Шаг 2. Скопируй SSH-ссылку своей копии

На странице своего нового репозитория нажми зелёную кнопку «Code», выбери вкладку «SSH» и скопируй ссылку — она выглядит примерно так: 

git@github.com:твой-аккаунт/day01-hello-cpp.git

Шаг 3. Открой терминал в папке, где хочешь хранить задания

Например, создай папку cpp-course и перейди в неё:

mkdir cpp-course
cd cpp-course

Шаг 4. Склонируй свою копию

git clone git@github.com:твой-аккаунт/day01-hello-cpp.git

Появится папка с названием репозитория — внутри уже будут все файлы задания.

Шаг 5. Перейди в папку с проектом

cd day01-hello-cpp

Теперь можно открывать файлы в редакторе кода (например, VS Code: code .) и начинать работу.

Так как это уже твоя копия, git push будет отправлять изменения именно в неё — никаких дополнительных настроек не нужно. Как коммитить и пушить — смотри в гайде «Git с нуля».
