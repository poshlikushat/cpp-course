Работаешь за компьютером в школе?

На школьном компьютере один логин на весь класс, поэтому настраивать SSH-ключ или токен там не стоит — всё, что ты сохранишь на диске, будет доступно следующему ученику. Никакой настройки git тут не нужно вообще.

Шаг 1. Склонируй задание по ссылке

Открой ссылку на репозиторий задания (её даёт преподаватель). Нажми зелёную кнопку «Code», выбери вкладку «HTTPS» (не SSH!) и скопируй ссылку — она выглядит так: 

https://github.com/your-org/day01-hello-cpp.git

В терминале:

git clone https://github.com/your-org/day01-hello-cpp.git
cd day01-hello-cpp
Для клонирования по HTTPS не нужен ни SSH-ключ, ни логин на GitHub — репозиторий с заданием публичный, скачать его может кто угодно. Никаких следов на компьютере после этого не остаётся, удалять после урока нечего.

Шаг 2. Пиши код

Открой склонированную папку в редакторе (например VS Code) и работай как обычно.

Шаг 3. Сдай работу

Дальше — как скажет преподаватель, есть два варианта:

Вариант А. Через чекер

Заархивируй папку с решением в zip и загрузи в чекер (адрес даст преподаватель, обычно вида http://localhost:3000). Он сам проверит форматирование, cppcheck и тесты — ничего на GitHub заливать для этого не нужно.

Вариант Б. Загрузить решение на GitHub вручную (без терминала)

  1. Если ещё не делал — создай свою копию репозитория задания через кнопку «Use this template» на странице репозитория (это просто клик на сайте, ничего не нужно устанавливать)
  2. Зайди в свою копию репозитория на github.com
  3. Нажми «Add file» → «Upload files»
  4. Перетащи изменённые файлы в окно браузера
  5. Внизу впиши короткое сообщение о том, что сделал, и нажми «Commit changes»
Это происходит через сайт GitHub в браузере — не забудь выйти из своего аккаунта (значок профиля → Sign out) в конце урока, раз компьютер общий.
Работаешь из дома или со своего ноутбука? Тебе не сюда — смотри обычный флоу: SSH-ключ → Клонирование → Git с нуля.
